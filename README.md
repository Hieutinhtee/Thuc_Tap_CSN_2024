# 🏢 Website Quản Lý Nhân Sự - FourH

## 📌 Giới thiệu
Dự án được xây dựng nhằm **quản lý thông tin nhân sự trong doanh nghiệp** một cách hiệu quả, giúp công ty FourH tự động hóa các quy trình quản lý nhân viên, phòng ban, lương, chấm công và lịch công tác.

Website cung cấp công cụ hỗ trợ người quản trị và nhân viên dễ dàng truy cập, theo dõi, và cập nhật thông tin nhân sự — giảm thiểu khối lượng công việc thủ công và tăng hiệu suất làm việc trong doanh nghiệp.

---

## 🧩 Tính năng chính

### 👨‍💼 Dành cho nhân viên
- Đăng nhập và thay đổi mật khẩu.  
- Xem thông tin cá nhân, bảng lương, lịch công tác.  
- Gửi đơn xin nghỉ phép trực tuyến.  

### 🧑‍💻 Dành cho quản trị
- Quản lý **nhân viên**: thêm, sửa, xóa, tìm kiếm.  
- Quản lý **phòng ban, chức vụ, bậc lương, bằng cấp**.  
- Quản lý **chấm công** và **lịch công tác**.  
- Quản lý **tài khoản** người dùng.  
- Xem **thống kê và báo cáo tổng hợp**.  

---

## 🛠️ Công nghệ sử dụng
- **Ngôn ngữ:** PHP, HTML, CSS, JavaScript  
- **Cơ sở dữ liệu:** MySQL  
- **Framework:** Bootstrap  
- **Môi trường phát triển:** XAMPP, Visual Studio Code  
- **Công cụ hỗ trợ:** phpMyAdmin, MySQL Workbench  

---

## 🗂️ Cấu trúc hệ thống
- `index.php`: Trang chính.  
- `admin/`: Giao diện quản trị (quản lý nhân sự, phòng ban, chấm công...).  
- `employee/`: Giao diện nhân viên (xem thông tin, lương, công tác...).  
- `includes/`: Các file cấu hình, xử lý kết nối CSDL.  
- `assets/`: CSS, JS, hình ảnh và các tài nguyên tĩnh.
